# Project instructions

Before changing the project, read the four files in `docs/ai/` in this order:

1. `context.md`
2. `architecture.md`
3. `current-milestone.md`
4. `workflow.md`

After completing work, update the relevant `docs/ai/` files as required by
`docs/ai/workflow.md`. Keep them aligned with the code, tests, commits and the canonical project
documentation.
