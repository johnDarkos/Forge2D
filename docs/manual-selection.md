# Ручное выделение целого спрайта

Этот режим позволяет вырезать персонажа целиком, когда сетка делит его на части.
Границы задаёт пользователь; автоматического распознавания персонажей нет.

## Как пользоваться

1. Загрузите изображение через Choose File.
2. Нажмите Select region.
3. Зажмите левую кнопку мыши у одного угла персонажа и протяните рамку к
   противоположному углу. Включите в рамку оружие и другие нужные детали.
4. Отпустите кнопку и проверьте результат в Preview на панели Tools слева.
5. Нажмите Download PNG — скачается `selection.png` в исходном разрешении.

Можно тянуть рамку в любом направлении. Zoom in / Zoom out помогают точнее
выбрать границы, средняя кнопка мыши перемещает изображение. Масштаб просмотра
не увеличивает и не уменьшает экспортируемый PNG.

Clear region очищает выбор. Новая рамка заменяет предыдущую. Escape во время
перетаскивания отменяет только текущий жест и сохраняет предыдущую область.
Простой клик или линия без площади не создают новую область.
Выход за изображение ограничивает рамку его границами.

Grid mode возвращает сетку и пакетный экспорт. Переключение режима и загрузка
другого файла очищают выделение. Пока рисуется рамка, скачивание недоступно;
во время экспорта изменение источника и выбора заблокировано.

## Несколько кадров в одном ZIP

1. Обведите первого персонажа и нажмите **Add frame** под Preview в панели Tools.
2. В блоке **Saved frames** появится миниатюра. Текущая рамка очистится,
   чтобы можно было выделить следующего персонажа.
3. Повторите для остальных кадров. Поле **Frame … name** меняет имя кадра,
   **Remove** удаляет его из списка.
4. Нажмите **Export ZIP** — получите `<имя исходника>_sprites.zip` со всеми
   добавленными кадрами. Не добавленная в список рамка в этот ZIP не входит.

Download PNG по-прежнему скачивает только текущую рамку как `selection.png`.
Сохранённые кадры остаются при новом выделении, Clear region и переключении
между Grid mode и Select region. В режиме сетки Export ZIP относится к выбору
ячеек; для ZIP ручных вырезок вернитесь в Select region.

Список существует в памяти текущей сессии. Загрузка другого файла или
перезагрузка страницы очищает его. Экспорт не очищает список.
Во время рисования Add frame и экспорт заблокированы; во время экспорта нельзя
добавлять, переименовывать или удалять кадры. Ошибка экспорта сохраняет список
для повторной попытки; частичный архив не скачивается.

Изначальные имена — `frame_001`, `frame_002` и так далее. Удаление не меняет
имена и ID остальных кадров; новые номера не переиспользуются. ZIP содержит
кадры в порядке добавления. Расширение `.png` добавляется автоматически.
Пустое имя заменяется исходным номером, символы путей и недопустимые символы
заменяются, зарезервированные имена вроде `CON` получают префикс `_`.
Совпадения без учёта регистра получают суффиксы: `idle.png`, `idle_2.png`.
Нормализация применяется к файлам архива и не переписывает текст в полях.

## Что сохраняется

PNG содержит все пиксели внутри прямоугольника, включая фон, если он присутствует
в исходнике. Прозрачность исходника сохраняется. Рамка и подсветка не попадают
в файл. Этот инструмент не удаляет фон и не объединяет разрозненные части.
Одновременно рисуется одна область; добавленные вырезки накапливаются в списке.

## Реализация и проверки

Чистая функция `selectionRect` нормализует две точки, ограничивает область
размерами изображения и округляет внешние границы до целых пикселей:
левую/верхнюю вниз, правую/нижнюю вверх. Нулевой размер даёт `null`.

`useRegionSelection` переводит координаты указателя в исходные пиксели через
`getBoundingClientRect`, учитывая CSS-масштаб и перемещение. Черновик остаётся
в feature; завершённая область хранится в `useEditor`. Preview и экспорт
получают одну и ту же геометрию. Экспорт использует существующий `exportFrame`.

19 проверок Vitest покрывают геометрию, действия пользователя, отмену, сброс,
список, имена файлов, блокировки и ошибку кодирования. Четыре сценария Playwright
проверяют настоящий PNG, включая пользовательский `src/test/fixtures/test.png`:
скачанные пиксели сравниваются с исходной областью, в том числе после Zoom/Pan,
обратного жеста и извлечения нескольких кадров из ZIP.
Команды и ограничения моков — в [руководстве тестирования](test/testing.md).
